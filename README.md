# Shine Bros Window Cleaning

Professional window cleaning website for **Shine Bros Window Cleaning**, serving Charlotte, NC and the surrounding metro area.

## Live Demo

[View on Claude Artifact](https://claude.ai/artifact/QTYBJuhnvMpKbZwWEXvXvc)

## Features

- Cinematic intro video overlay (Higgsfield AI generated)
- Hero section with full-screen background
- Before/After interactive slider
- Services & pricing plans
- How it works walkthrough
- Google Maps service area with city list overlay
- Customer reviews
- FAQ accordion
- Contact form
- Mobile-responsive design
- Dark/light theme support

## Service Areas

Charlotte, Ballantyne, Waxhaw, Marvin, Myers Park, Dilworth, SouthPark, Mint Hill

## Tech

Single-file HTML/CSS/JS — no build step required. Open `index.html` in any browser or deploy directly to:

- **GitHub Pages** — Settings → Pages → Deploy from `main` branch
- **Netlify** — Drag and drop this repo
- **Vercel** — Import repo, deploy instantly

## Deploy to GitHub Pages

1. Go to repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / `/ (root)`
4. Save — site will be live at `https://noambin1.github.io/The-Shine-Bros-Window-Cleaning`
